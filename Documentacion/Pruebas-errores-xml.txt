==================================================
1. INTRODUCCION
==================================================

En este apartado se realizan dos pruebas para comprobar la detección y corrección de errores en documentos XML.

El objetivo es verificar que el documento XML está bien formado y que cumple las reglas establecidas en el archivo DTD.

Para realizar las pruebas se ha utilizado la clase PruebasXML.java.

==================================================
2. PRIMER ERROR: ETIQUETA SIN CERRAR
==================================================

Descripción del error:

Se eliminó temporalmente la etiqueta de cierre </nombre> del jugador Alex.

Código con el error:

```xml
<nombre>Alex
```

Resultado obtenido:

Java detectó el error y mostró el siguiente mensaje:

```text
The element type "nombre" must be terminated
by the matching end-tag "</nombre>".
```

Explicación:

El error se produjo porque la etiqueta nombre se abrió, pero no se cerró correctamente.

Solución aplicada:

Se volvió a escribir la etiqueta de cierre:

```xml
</nombre>
```

Resultado final:

El error quedó corregido y el elemento nombre volvió a estar correctamente formado.

==================================================
3. SEGUNDO ERROR: ELEMENTO OBLIGATORIO AUSENTE
==================================================

Descripción del error:

Se eliminó temporalmente el elemento puntuacion del jugador Alex.

Código con el error:

```xml
<jugador>
    <nombre>Alex</nombre>
</jugador>
```

Resultado obtenido:

Java detectó el error y mostró el siguiente mensaje:

```text
The content of element type "jugador" is incomplete,
it must match "(nombre,puntuacion)".
```

Explicación:

El error se produjo porque el DTD establece que cada elemento jugador debe contener obligatoriamente un elemento nombre seguido de un elemento puntuacion.

Solución aplicada:

Se volvió a añadir el elemento puntuacion:

```xml
<puntuacion>450</puntuacion>
```

Resultado final:

El jugador volvió a cumplir la estructura establecida en el archivo DTD.

==================================================
4. COMPROBACION FINAL
==================================================

Después de realizar las dos pruebas, se restauró el archivo ranking.xml a su estado original.

Se comprobó que el documento volvía a ser válido según el DTD.

El resultado obtenido fue:

```text
XML válido según el DTD.
```
